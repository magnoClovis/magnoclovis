## About me

I'm Magno, a Computer Engineering student at Universidad Pablo de Olavide and a teacher of programming, robotics, and technology.

I see programming as a vehicle for logical reasoning and structured thinking, not as an exercise in memorizing syntax. I enjoy turning complex ideas into practical projects and learning experiences that make technology easier to understand.

Fun fact: I love dancing and swimming! 🕺🏾 🏊🏾

### Featured projects

- **[Trofia](https://github.com/magnoClovis/nutrition-tracker)**: a nutrition tracking app I built from scratch for meals, goals, water, supplements, body metrics, and AI-assisted features. Built with React, Vite, Capacitor for Android, Firebase, Cloudflare Workers, and the Gemini API. Currently in beta, with a [live web version](https://magnoclovis.github.io/nutrition-tracker/) and Android internal testing.
- **[Deep Learning Projects](https://github.com/magnoClovis/Deep-Learning-Projects)**: supervised and unsupervised learning experiments with ANNs, CNNs, RNNs, autoencoders, Boltzmann machines, and self-organizing maps. Built in Python with TensorFlow/Keras, PyTorch, scikit-learn, MiniSom, NumPy, Pandas, and Matplotlib.
- **[Professional portfolio](https://magnoclovis.github.io/clovis-magno/)**: a multilingual static website presenting my professional profile and projects, built with HTML and CSS. [Source code](https://github.com/magnoClovis/clovis-magno).
